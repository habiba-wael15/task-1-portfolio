# Habiba Wael - Personal Portfolio

A responsive personal portfolio website built as part of **Task 1: Static Portfolio Website with a Theme** for the **Saiket Systems Full Stack Development Internship**.

This portfolio showcases my background, technical skills, projects, and contact information through a modern, clean, and responsive interface.

## Features

- Professional Home / Hero section
- About Me section
- Technical Skills section
- Projects showcase
- Private Project labels for non-public projects
- Contact form
- JavaScript form validation
- Dark / Light theme toggle
- Fully responsive design
- GitHub and LinkedIn links
- Direct Gmail contact
- Bootstrap 5 styling
- Bootstrap Icons

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

Running the Project Locally
This is a static website, so no backend setup is required.
Clone the Repository
git clone https://github.com/habiba-wael15/task-1-portfolio.git

Navigate to the Project
cd task-1-portfolio

Run the Website
You can open index.html directly in your browser.
Alternatively, you can run a local development server:
python -m http.server 8765

Then open:
http://localhost:8765
